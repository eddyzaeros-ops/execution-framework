## 2. 三大維度詳細技術規範

### 維度 01：物理隔離與資料入庫（Physical Isolation & Ingestion）
1. **實體單向隔離光閘（Data Diode）**：所有外部公開文獻、開源權重與套件依賴庫，僅能透過單向光閘或硬體唯讀媒介導入，杜絕網路層與實體層的雙向外洩通道。
2. **入庫合規與靜態消殺驗證**：進入隔離網段前，執行多防毒引擎消殺、格式語法驗證與敏感標籤審計，阻斷惡意 Payload 藉由訓練集或 RAG 文件暗中混入。
3. **離線離子化知識庫（Offline Document Repository）**：建立離線版軍規標準手冊（MIL-STD）、科學模擬規格書，以純文字 Markdown 存放，免除外部連網依賴。
4. **嚴格授權與身分硬體鎖**：研發人員存取推論伺服器需使用智慧卡（Smart Card / FIDO2）硬體憑證。

### 維度 02：地端核心智慧與調度（On-Prem Core Intelligence）
1. **Google Gemma 31B 稠密模型**：於單張 A100 或 RTX 4090（Q4_K_M）實現全地端高效推論，零外部 API 依賴。
2. **雙軌專業 Harness 框架**：整合 OpenCode（代碼工程約束）與 Nous Hermes Agent（工具決策循環）。
3. **LangChain DeepAgents 多層調度**：以 Supervisor-Worker 模式協同多個專職 Sub-Agent，將複雜任務拆解為可控有限狀態。
4. **Git-Backed 本地第二大腦**：決策日誌、反思與踩坑教訓沉澱至私有 Git Repo 與 Obsidian Vault。

### 維度 03：國防級沙箱執行與審計（Defense-Grade Sandboxed Execution）
1. **確定性密封沙箱（Deterministic Sandbox）**：Python/C++ 運算腳本均在斷網 Docker / gVisor 沙箱內運行，隔離主機系統。
2. **AST 語法樹靜態安全閘（AST Security Gate）**：代碼執行前由 Pre-Tool Hook 解析 AST 樹，嚴格攔截危險系統呼叫（如 `socket`、`subprocess`、`rm -rf`）。
3. **仿真 API 受控適配器（Simulation API Connectors）**：僅開放白名單驗證之本地 CAE 求解器（結構、熱力、流體網格），嚴禁武器殺傷鏈接駁。
4. **不可篡改之唯讀審計日誌（Read-Only Audit Log）**：全推論鏈與工具呼叫參數賦予唯一 UUID Trace ID，實時寫入唯讀稽核存儲。
