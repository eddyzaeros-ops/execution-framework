## 📑 文件摘要 (Document Summary)

針對專業領域痛點（缺乏標註資料、領域知識壁壘高、動態法規與機敏要求），系統性評估四種主流 AI 技術路線：微調專用模型（Fine-Tuning）、領域知識 RAG、前置模型 + AI Agent（ReAct 迴圈）、以及專用模型與通用模型混成之 Agent 協同架構。確立以「前置地端開源模型 + 專用 Harness + 外部系統整合」為最適落地路徑。
