## 📑 文件摘要 (Document Summary)

引述國際權威專家（Karpathy 軟體 2.0/3.0 與 Agentic System 定義、Andrew Ng 關於多輪迭代推理超越單次大模型之論述），對比全球主流 Harness 生態（Hermes Agent、OpenCodeInterpreter、LangChain DeepAgents）與地端主流開源模型（Nemotron、Kimi、Gemma-3-27B、Ornith）。透過 Matplotlib 繪製四種路線的能力差距雷達圖、專家共識圖與成本效能曲線圖，並將專屬 MCP 工具鏈（Anduril Lattice Menace、EADSIM、MIS 戰術系統）納入編排架構。
